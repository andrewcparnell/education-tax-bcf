# Phase 6 Forensic Code & Data Audit Report (Reviewer 5)

### 1. Overall impression

The continuous-treatment redesign of the repository (`src/r/01_download_tax_education_data.R` through `src/r/06_generate_figures_and_diagnostics.R`, `src/cpp/mvbcf_source_code.cpp`, `app/prepare_app_data.R`, `tests/test_pipeline.R`, and `paper/paper.tex`) is a substantial methodological and engineering upgrade over the earlier binary-threshold version. The four-outcome continuous-dose Multivariate Bayesian Causal Forest sampler (`src/cpp/mvbcf_source_code.cpp`) is mathematically exact for continuous treatments: both the leaf-level marginal log-likelihood (`log_lik_tau`, lines 525-577) and the conjugate multivariate normal leaf update (`update_tau`, lines 70-103) form the exact continuous precision matrix $\Lambda_{\tau,\ell} = \Sigma_\tau^{-1} + (\sum_{i \in \ell} Z_i^2)\Sigma^{-1}$ and sufficient statistic $\Sigma^{-1}\sum_{i \in \ell} Z_i r_i$, matching Appendix A of `paper/paper.tex`. Furthermore, the country-blocked 5-fold split (`country_fold` 1 to 4 training vs `country_fold == 5` locked holdout test set) is constructed deterministically in `src/r/02_build_clean_tax_panel.R` (lines 244-281) before computing income-group centring medians (`inc_meds`, computed strictly on `is_holdout_test == 0L`), and both `estimate_rf_z_hat` (`src/r/04_run_mvbcf_tax_models.R`, lines 161-191) and `evaluate_country_split` (`src/r/04_run_mvbcf_tax_models.R`, lines 515-550) cross-fit covariate medians and the 500-tree Random Forest treatment expectation $\hat{z}(X)$ strictly out-of-fold by country. Every single number, credible interval, posterior probability $P$, sample size $N$, CRPS, and table cell across all primary causal and diagnostic tables of `paper/paper.tex` matches the CSV files in `outputs/tables/` with 100% accuracy, and both `Rscript tests/test_pipeline.R` and `python3 scripts/check_style.py --warnings-as-errors --data-plural error --all .` pass with zero errors.

My line-by-line forensic audit identified the following items to clean up:
1. **Unused legacy binary-treatment scripts (`src/cpp/lbcf_3wave.cpp`, `src/r/05_run_longitudinal_bcf_tax.R`, `src/r/07_publishability_gate_diagnostics.R`):** Because Longitudinal BCF (`lbcf_3wave`) was dropped from the paper by user decision, these legacy files (where `lbcf_3wave.cpp` had `double nz = sum(node_z);` for binary `Z`) are no longer part of the active pipeline (`04_run_mvbcf_tax_models.R` does not call `lbcf_3wave.cpp`) and should be removed or archived so the repository contains only clean, active continuous-treatment code.
2. **Stale numbers and a non-existent CSV path in `paper/paper.md`:** Whilst `paper/paper.tex` is synchronised with `outputs/tables/*.csv`, `paper/paper.md` (Table 2 and Appendices B, C, and D) retains numbers from an earlier run and cites `outputs/tables/table_scaling_ab_comparison.csv` instead of `outputs/tables/table_scaling_fit_and_residuals.csv` and `outputs/tables/table_holdout_country_validation.csv`.
3. **Consistency of `med_spend_winsor` vs `med_spend_raw` in `06_generate_figures_and_diagnostics.R` (`tableA4`) and `paper/paper.tex` line 167:** In `02_build_clean_tax_panel.R`, `Z_cont_10pp` (`Scaling A`) is centred on `med_spend_winsor` (`150.0%`, `71.1%`, `27.9%`, `26.4%`), whereas `Z_cont_log25pct` (`Scaling B`) is centred on `med_spend_raw` (`183.8%`, `68.9%`, `27.6%`, `26.4%`). In `06_generate_figures_and_diagnostics.R` (`tableA4`), `gap_to_median_pp` should be computed against `med_spend_winsor` (`150.0%`, `71.1%`, `27.9%`, `26.4%`) so that `gap_to_median_pp / 10` equals `1.5 - Z_cont_10pp` for every row in `tableA4_latest_z0_countries_costs_and_returns.csv`.
4. **Separate filename for the Section 3 4-panel data overview figure (`fig0_panel_data_overview.pdf` or keeping `eda_fig1_raw_distributions_and_bivariate.pdf` consistent between `eda/figures/` and `outputs/figures/`).**
