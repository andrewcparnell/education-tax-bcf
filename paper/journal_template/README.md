# Preprint Template Notes

Target venue: **arXiv Preprint** (`stat.AP` / `econ.GN` / `stat.ME`), formatted for direct arXiv TeX submission (`pdflatex` + `bibtex`).

Because arXiv compiles standard TeX Live classes without proprietary publisher class files, `paper/paper.tex` uses a clean, self-contained `article` layout (`11pt`, `a4paper`, `geometry`, `booktabs`, `natbib` with `abbrvnat`, `amsmath`, `amssymb`, `graphicx`, `hyperref`, and `microtype`) modelled on *Journal of the Royal Statistical Society: Series A* (McJames et al., 2024) and *Bayesian Analysis* (Hahn et al., 2020).
